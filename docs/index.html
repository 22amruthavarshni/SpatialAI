The pipeline

Six phases, each producing a working, independently-verified output before the next begins. Nothing here is a black box — every stage's failure modes are known and documented.

01

Detection

YOLOv8 locates objects in each frame — class, confidence, bounding box.

02

Depth

MiDaS infers relative per-pixel distance from a single 2D image.

03

Camera Pose

COLMAP solves where every photo was taken from, via Structure from Motion.

04

Reconstruction

Gaussian Splatting builds a dense, renderable 3D scene from sparse points.

05

Fusion

Detections, depth, and pose are unified into one 3D coordinate system.

06

Scene Graph

Objects, positions, and distances — a structure a program can query.

01

Object Detection

A pretrained YOLOv8 model finds objects in every frame. Box color corresponds to class — cyan for laptop/cup/keyboard, lime for books, magenta for the chair.

yolov8m · confidence threshold 0.4
book 0.44 · laptop 0.85 · chair 0.40
Known limitation: the mouse and mousepad were consistently misclassified as “book” — COCO's 80 classes don't include either, so the model picks its closest known category. Confidence thresholding (0.4) and upgrading nano→medium removed a phantom “person” false-positive caused by the chair's backrest silhouette.
02

Depth Estimation

MiDaS infers a per-pixel distance map from a single photograph — no depth sensor, no stereo pair. Brightness encodes proximity: yellow is near, violet is far.

MiDaS outputs relative depth, not metric units — it knows what's closer, not how many centimeters away. Bridging that gap to real-world scale is what Phase 5's fusion step solves.
03

Camera Pose Estimation

COLMAP matches keypoints across all 36 frames and solves — via Structure from Motion — where the camera stood and which way it faced for every single shot, plus a sparse 3D point cloud as a byproduct.

Flat, low-texture surfaces — the white desk, the chair's smooth frame — produced almost no matchable keypoints and remain sparse. This is expected: sparse SfM is only solving for camera geometry, not full-surface coverage. Dense coverage is Phase 4's job.
04

Dense Reconstruction

Gaussian Splatting initializes thousands of 3D blobs from the sparse point cloud, then refines each one's position, color, and shape by comparing rendered views against the real photographs.

The chair's mesh backrest — the same low-texture region that starved sparse reconstruction — started with the fewest Gaussians and stayed visibly blurred even at 3K iterations. Full training let densification catch up: edges sharpened noticeably by 30K, though the finest mesh lines remain a known soft spot.
05–06

Fusion & Scene Graph

Detections (2D pixels), depth (relative distance), and camera pose (real 3D geometry) live in three incompatible coordinate systems. Fusion unprojects every detection into COLMAP's shared 3D world — using a MiDaS→COLMAP scale factor of 0.0151, derived from 138,677 point observations — then clusters repeated sightings of the same object into one robust position per class.
